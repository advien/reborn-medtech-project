## Фаза B — ML на открытых данных → статья `drift_personalization`

- [x] **B0.** Слой данных: `reborn/data/` (загрузчики, конвейер, протоколы, тесты)
- [x] **B1.** Ninapro DB6, испытуемые s01–s02 (20 сессий, 4.1 ГБ) → `data/ninapro_db6/`
- [x] **B2.** Проверено на реальных файлах: шаблон имён совпал; пороги откалиброваны →
      [`experiments/configs/ninapro_db6_qc.json`](../../experiments/configs/ninapro_db6_qc.json).
      Три находки: колонки 8–9 — паддинг; `flatline_std` тоже абсолютный и его надо выводить;
      `corruption.py` тоже в абсолютных амплитудах, иначе детекция меряет масштаб, а не детектор
- [x] **B3.** Notebook 01 исполнен на реальных окнах s01 (10 сессий, 136 234 окна).
      QC-отбраковка **0.67%**, причина — `dropout`; сессия `d04_t01` 3.57% (13.5× медианы) —
      сигнальное событие, а не шум. Детекция масштабированных инъекций: dropout/saturation/
      clipping/baseline_offset 100%. **Находка:** advisory-детектор (rms/mav/zcr + Махаланобис)
      на реальных данных ловит только baseline_offset (100%), а `noise_burst` — 2.8% (ниже clean
      4.4%). Три time-domain фичи ему не дают тяги; нужен богаче признак (частотный) прежде чем
      advisory-слой оправдает себя. → отдельный пункт B3a.
- [x] **B3a.** `anomaly_features` = Hudgins + спектральные (mean-freq, HF-ratio) + импульсные
      (kurtosis, crest, sub-window RMS). На реальном s01: saturation/clipping 16%/9% → **100%**,
      noise_burst (severity 3) 2.8% → **~34%** (выше clean). Sweep по энергии: sev1≈clean,
      sev3 41%, sev5 75–96%, sev8 ~100% — детекция есть **выше энергетического порога**, короткий
      слабый всплеск на уровне окна неотличим от вариации EMG. **Остаток:** clean false-positive
      вырос 4.4% → 8.8% (10 признаков на ~250 окнах обучения) → B3b.
- [ ] **B3b.** Вернуть clean false-positive к ~2.5% (отбор признаков / больше окон на fit),
      не потеряв выигрыш по noise_burst.

## Инварианты, которые легко нарушить в спешке

1. Ноутбук зовёт `reborn.sensing`, а не пишет свой препроцессинг.
2. Сплиты — по сессиям и субъектам. Random shuffle только как помеченный контроль.
3. QC до ML. Процент отбраковки — результат, а не служебное число.
4. Ноутбук порождает артефакт (CSV), фигуры рисует отдельный скрипт из этого CSV.
5. Никаких «novel»/«first»/«state-of-the-art», пока фаза A не ответит.
